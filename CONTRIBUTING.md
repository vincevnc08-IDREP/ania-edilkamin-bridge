# Contribuer

Ouvrir une issue avec le modèle exact du poêle, les références des cartes et les versions utilisées. Ne jamais publier de mots de passe, jetons ou captures non anonymisées.

Pour proposer une modification : branche dédiée, changement ciblé, tests hors matériel de `docs/VALIDATION.md`, puis pull request expliquant comportement avant/après et validations. Une compilation réussie n’est pas une validation radio.

Pour ajouter un état ou une commande, joindre une observation indépendante de l’effet réel. Ne pas déduire marche/arrêt d’un octet corrélé à une seule capture. Les expériences de chauffe doivent rester supervisées ; ne pas contourner les protections du poêle.

Les contributions originales sont soumises sous GPL-3.0-or-later. Préserver les mentions de licence des dépendances.
